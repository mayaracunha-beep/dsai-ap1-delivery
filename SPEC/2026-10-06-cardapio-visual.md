# SPEC — Cardápio Visual do DeliveryFast

Data: 2026-10-06

## Objetivo

Melhorar a interface do DeliveryFast, tornando o cardápio mais completo,
visual e semelhante a uma aplicação real de delivery.

## Motivação

A versão atual apresenta informações básicas dos restaurantes.
A nova versão deverá facilitar a visualização dos produtos e melhorar
a experiência do usuário durante a escolha dos pedidos.

## Critérios de aceitação

1. Os produtos devem possuir imagem.
2. Cada produto deve apresentar nome.
3. Cada produto deve apresentar descrição.
4. Cada produto deve apresentar preço em reais.
5. Cada produto deve possuir botão "Adicionar ao carrinho".
6. O usuário deve conseguir visualizar restaurantes por categoria.
7. O carrinho deve mostrar os produtos adicionados.
8. O carrinho deve apresentar subtotal, taxa de entrega e total.
9. A interface deve funcionar em computador e celular.

## Categorias

- Hambúrgueres
- Pizzas
- Comida italiana
- Sushi
- Bebidas
- Sobremesas

## Fora do escopo

- Pagamento real.
- Integração com cartão de crédito.
- Rastreamento real de entregador.
- Integração com restaurante real.
